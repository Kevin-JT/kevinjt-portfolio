PROMPT C — Plugin Loader (Most Critical — Dedicated Session)
Implement a complete runtime .cs3 plugin loader for OpenStream.
This is the most critical feature — without it the app shows no content.

A .cs3 file is a renamed .jar/.dex file containing compiled Kotlin classes
that extend CloudStream's MainAPI abstract class.

Implement ALL of the following completely:

1. PLUGIN LOADER ENGINE
   File: core/plugins/PluginLoader.kt

   class PluginLoader @Inject constructor(
       @ApplicationContext private val context: Context
   ) {
       // Use PathClassLoader to load .cs3 file from local storage path
       // Use reflection to find classes extending MainAPI
       // Instantiate the plugin class safely
       // Return a PluginResult (Success/Failure) sealed class
       // Cache loaded plugins in a HashMap<String, MainAPI>
       // Handle ClassNotFoundException, NoSuchMethodException gracefully
       // Log all errors without crashing
   }

2. MAIN API INTERFACE BRIDGE
   File: core/plugins/MainAPIBridge.kt
   
   Define the interface that all loaded plugins must satisfy:
   - getName(): String
   - getMainUrl(): String  
   - search(query: String): List<SearchResponse>
   - load(url: String): LoadResponse
   - getMainPage(page: Int, request: MainPageRequest): HomePageResponse
   
   Use reflection to call these methods on loaded plugin instances
   because the plugin classes are loaded at runtime and not available
   at compile time.

3. EXTENSION MANAGER
   File: core/plugins/ExtensionManager.kt
   
   - downloadExtension(apkUrl: String, name: String): Flow<DownloadState>
     · Download .cs3 file to context.getExternalFilesDir("extensions")
     · Show download progress via Flow
     · On complete, call PluginLoader.load(filePath)
     · Update Room DB: isInstalled=true, localPath=filePath
   
   - loadAllInstalledExtensions()
     · Query Room DB for all isInstalled=true extensions
     · Call PluginLoader for each one
     · Skip silently if file missing (don't crash)
   
   - unloadExtension(pluginId: String)
     · Remove from PluginLoader cache
     · Update Room DB: isInstalled=false
     · Do NOT delete the file
   
   - getLoadedPlugins(): List<MainAPI>
     · Return all currently active plugin instances

4. SEARCH AGGREGATOR
   File: core/plugins/AggregatedSearch.kt
   
   - searchAll(query: String): Flow<List<SearchResponse>>
     · Call search() on ALL loaded plugins in parallel (async)
     · Emit results as each plugin responds (don't wait for all)
     · Catch exceptions per plugin — one failure must not stop others
     · Merge and deduplicate results by URL

5. HOME PAGE AGGREGATOR  
   File: core/plugins/HomePageAggregator.kt
   
   - getHomePage(): Flow<List<HomeSection>>
     · Call getMainPage() on all loaded plugins in parallel
     · Each plugin returns rows (HomeSection with title + items)
     · Merge all rows into one combined list for the Home screen
     · Emit loading state, then content state, then done state

6. PLUGIN SECURITY
   - Only load files from context.getExternalFilesDir("extensions")
   - Reject any file not ending in .cs3
   - Wrap every reflection call in try-catch
   - Never allow a plugin crash to crash the host app

7. VIEWMODEL INTEGRATION
   Update HomeViewModel to use HomePageAggregator
   Update SearchViewModel to use AggregatedSearch
   Both must expose:
   - UiState sealed class: Loading | Success(data) | Error(message) | Empty
   - StateFlow<UiState> observed by Compose screens

Output every class completely. No TODOs. No truncation.
